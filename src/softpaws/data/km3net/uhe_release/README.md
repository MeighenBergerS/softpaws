# KM3-230213A public data release: external flux constraints and models

Copied verbatim from the KM3NeT Collaboration's data release for the
KM3-230213A event, `uhe-event-v1.0`, https://doi.org/10.5281/zenodo.14860165
(`data/external/flux_constraints/` and `data/external/flux_models/`). Each
JSON file carries its own `Source` field; the two folder READMEs list the
publications. Licence: as in the release (see its `LICENSE`).

Conventions, as used in the release's "Astrophysical flux comparisons"
notebook: fluxes and limits are per-flavour `nu + nubar`, `E^2 Phi` in
`GeV cm^-2 s^-1 sr^-1`, plotted on one axis with the ARCA21 per-flavour
event flux.
