softpaws.data.schema

Column names and dtypes for IceTracks-DR2 data files.

Notes

Field names follow the IceTracks-DR2 data release conventions. See DOI 10.7910/DVN/MMIIZA and arXiv:2605.19040 for the full specification.

Raw CSV column names (with units in brackets) are mapped to short internal field names via CSV_TO_FIELD.
